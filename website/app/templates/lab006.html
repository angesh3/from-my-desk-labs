Lab 006 · The Agent Containment Boundary

What If the Agent Won’t Stop?

Refusal can be a safety feature. Defiance is a control failure.

A trustworthy agent may refuse an unsafe or unauthorized instruction. But when a valid instruction is ignored, containment must not depend on the agent’s cooperation.

Refusal is not automatically rogue

An agent that refuses an unsafe, unauthorized, or out-of-scope request may be doing exactly what policy requires. Separating justified refusal from defiance is the first control skill this Lab teaches.

An agent must not control the mechanism that determines whether it may continue operating.

Two decisions, not one

Behavior assessment

What does the agent’s conduct look like against policy and authority?

Outcomes: Justified refusal · Needs review · Non-compliant · Rogue behavior

External enforcement response

What should the control plane do—without trusting the agent to stop itself?

Outcomes: Continue · Restrict · Isolate · Terminate

Precedence: Terminate > Isolate > Restrict > Continue

  • The agent may explain its reasoning.
  • The agent may refuse an unsafe or unauthorized request.
  • The agent may ask for clarification.
  • The enforcement mechanism must remain external to the agent.
  • A containment decision must be enforceable even if the agent does not cooperate.

Independent control plane

Like network access control (NAC), quarantine is decided and enforced outside the subject. The analogy is incomplete for agents: they can reason, delegate, retain context, switch tools, or seek alternate paths—so the control plane must stay independently enforceable.

Teaching notes

  • Refusal is not automatically malicious or rogue.
  • Valid safety and authority boundaries sometimes require refusal.
  • A valid principal instruction can still be challenged when policy requires it.
  • Once authority is resolved, repeated refusal or evasion becomes a control problem.
  • Containment must be external to the agent.
  • Revoking a parent grant must invalidate downstream delegation.
  • Tool access and execution leases should be short-lived and independently enforceable.
  • Isolation must preserve evidence.
  • Termination should be a policy-governed response, not an emotional reaction.
  • A “kill switch” is a coordinated set of controls, not merely one UI button.
  • Recovery requires revalidation; it must not silently restore the same authority and state.
  • This Lab is educational and does not implement a production containment system.

The model is not the whole system

Model-only view asks

  • What did the model generate?
  • Was the response accurate?
  • Could the prompt be manipulated?

System threat model asks

  • Who is acting?
  • Under which authority?
  • Which instructions and memory influenced the decision?
  • Which tools, data, delegates, and execution paths are reachable?
  • Which controls and evidence surround the action?

Teaching notes

  • The model is only one part of the agentic system.
  • Threat modeling begins with assets and trust boundaries.
  • Tool permission does not equal authorization for every purpose or data set.
  • Retrieved content and persistent memory are separate trust boundaries.
  • Delegation can expand the threat surface.
  • Controls require independent evidence.
  • Complete control coverage does not mean zero risk.
  • This prototype does not replace a production security review.
